## 📖 Sobre o Projeto (Contexto & Bom Humor)

Este projeto nasceu como uma experiência descontraída, divertida e de alto impacto durante as aulas do curso de **Engenharia de Software com Inteligência Artificial**. 

O objetivo principal foi testar e estressar as capacidades de prototipagem rápida, engenharia de prompts, arquitetura de componentes e design visual assistido pelo **Google AI Studio**. E qual figura melhor para personificar intensidade, disciplina, carisma e momentos icônicos do que **Dwayne "The Rock" Johnson**?

> *"Não importa se você programa em C, Rust, Python ou TypeScript... IT DOESN'T MATTER WHAT YOU CODE! O que importa é acordar às 4h da manhã e colocar o trabalho na tela!"* — The Rock (provavelmente)

## ✨ Funcionalidades Eletrizantes

- 📷 **Galeria & Acervo de Fotografias Reais**:
  - Fotografias 100% autênticas de Dwayne Johnson (WWE Championship 2013, WrestleMania, estreia de Hércules em Sydney por Eva Rinaldi, retratos de estúdio por Jerry Avenaim e David Shankbone), com visualizador em alta definição e atribuições históricas.
- ☀️ / 🌙 **Modo Diurno & Noturno Temático**:
  - **Mana Day**: Tons solares acolhedores, areia dourada e estética premium de Venice Beach.
  - **Iron Paradise Dark**: O santuário das 4h da manhã, ferro fundido, preto obsidiana e luz tungstênio.
- 🤨 **Simulador Interativo da People's Eyebrow**:
  - Controle o ângulo exato da lendária sobrancelha arqueada do The Rock de 0% a 100%, acompanhado de efeito sonoro estrondoso sintetizado via Web Audio API.
- 🥞 **Calculador & Gerador de Cheat Meal Lendário**:
  - Descubra e gere os banquetes colossais de domingo do Dwayne: pilhas de panquecas com mirtilos, barcas monumentais de sushi, hambúrgueres duplos com queijo e potes infinitos de sorvete de amendoim, com contagem calórica precisa.
- 🏋️‍♂️ **Iron Paradise 4 AM Workout Selector**:
  - Rotinas reais de treino (Peito, Costas & Trapézios, Ombros de Titã, Pernas) com séries, repetições e a dose exata de Mana motivacional.
- 🎙️ **Soundboard de Frases & Efeitos Sonoros Web Audio**:
  - Áudios e frases marcantes em português e inglês ("Finalmente...", "It doesn't matter!", "Foco e Respeito") sintetizados em tempo real no navegador sem dependências externas.
- 🕶️ **Easter Egg: Modo Pochete & Gola Alta dos Anos 90**:
  - Um tributo interativo à foto mais famosa da história da internet: corrente de prata, camisa preta e a indefectível pochete de couro.

## 🚀 Como Rodar o Projeto

### Pré-requisitos
- Node.js (versão 18 ou superior)
- npm ou pnpm ou yarn
- Vontade de treinar pesado e comer panquecas

### Passo a Passo

1. **Clone o repositório:**
   ```bash
   git clone https://github.com/SEU-USUARIO/the-rock-fanpage.git
   cd the-rock-fanpage
   ```

2. **Instale as dependências:**
   ```bash
   npm install
   ```

3. **Inicie o servidor de desenvolvimento:**
   ```bash
   npm run dev
   ```

4. **Acesse no seu navegador:**
   ```
   http://localhost:3000
   ```

5. **Para gerar a build de produção:**
   ```bash
   npm run build
   ```

## ❓ Perguntas Frequentes (FAQ)

**1. O The Rock sabe da existência deste site?**  
Provavelmente ele está ocupado na Iron Paradise treinando perna ou gravando um filme de ação onde pula de um prédio para um helicóptero. Mas o Mana deste repositório certamente chegará até ele.

**2. Por que usar o Google AI Studio para isso?**  
Porque aprender Engenharia de Software com IA deve ser prático, dinâmico e divertido! Testar geração de interfaces completas, raciocínio de layout, manipulação de áudio Web API e estados de tema escuro/claro cria um laboratório de aprendizado muito mais rico do que mais uma lista de tarefas comum.

**3. Posso comer o Cheat Meal gerado pelo site?**  
Apenas se você treinar 3 horas por dia e tiver autorização do seu médico ou do próprio Dwayne Johnson.
